Workflow Laptop (VS Code) ⇄ iPhone

Cara Menjalankan & Update di iPhone

1. Cara Paling Mudah Buka di iPhone (Tanpa Ribet Kabel)

Karena iPhone (iOS) membatasi file .html jika dibuka langsung dari aplikasi Files/File, cara paling enak adalah meng-online-kan file ini secara gratis lewat Netlify Drop (app.netlify.com/drop) atau Vercel / GitHub Pages dari VS Code Anda:

  • Simpan kode ini di VS Code dengan nama index.html di dalam satu folder khusus (misal folder filephotoku-app).
  • Buka app.netlify.com/drop di browser laptop, lalu drag & drop folder tersebut. Anda akan langsung mendapat link pribadi (misal: filephotoku.netlify.app).

2. Jadikan Aplikasi Asli di Layar Utama iPhone (Full Screen)

Kode aplikasi ini sudah dilengkapi fitur iOS Web App. Setelah link terbuka di Safari iPhone:

  • Ketuk tombol Share / Bagikan (ikon kotak dengan panah ke atas di bagian bawah Safari).
  • Geser ke bawah lalu pilih "Add to Home Screen" (Tambah ke Layar Utama).
  • Sekarang ikon FILEPHOTOKU.STD muncul di layar iPhone Anda dan terbuka full-screen tanpa bar browser Safari!

3. Cara Live-Preview Langsung Saat Edit di VS Code

Jika ingin melihat perubahan kode detik itu juga di iPhone saat sedang mengetik di VS Code:

  • Install ekstensi Live Server di VS Code, lalu klik Go Live di pojok kanan bawah.
  • Pastikan Laptop dan iPhone terhubung ke WiFi/Hotspot yang sama, lalu buka alamat IP laptop Anda di Safari iPhone (contoh: http://192.168.1.5:5500).
